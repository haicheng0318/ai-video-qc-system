# V1.01 连续实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Track steps with checkboxes and preserve existing changes.

**Goal:** 完成用户批准的35项剩余升级，逐项验收，不把本地实现等同生产上线。

**Architecture:** 保留 Next.js / NestJS / PostgreSQL / Prisma 和已批准的千问接入。数据库队列与独立 worker 承担异步工作，统一账号会话与后台权限；管理端复用业务库，前台仅统一设计规范。

**Tech Stack:** Next.js 14 / React 18 / NestJS 10 / Prisma 6 / PostgreSQL / TypeScript。

**Spec:** docs/AI短视频质检评估系统V1.0-修订方案与使用问题审查-2026-09-07.md

## Global Constraints

- 保留全部12张核心表；三个等级独立存储，负责人确认不可省略。
- 沿用已批准的千问；不引入日常Claude评估，不改变业务规则。
- 访客仅自身内容评估和报告，试用数据排除正式统计。
- 密钥不进入前端、日志、报告、Git；不改已有云密钥。
- 日期口径 Asia/Shanghai。未知监控及费用显示未知，不伪造0。
- 现有未提交文件属于用户，禁止批量提交、清理、覆盖或回退。
- 生产迁移/会话退出/真实付费验收在维护窗口与预算确认后执行。

## 自检与实施裁决

| 关联任务 | 共享文件/接口 | 约束与处理 |
|---|---|---|
| 1/2/4 | schema、事务、AI服务 | 顺序实施迁移，额度/用量在既有事务扩展，不并发修改schema |
| 1/3 | jobId查询 | 原响应向后兼容，统一查询工具不引发重评 |
| 2/3 | Cookie与角色 | 先冻结后端契约再接前端，禁旧Bearer绕过 |
| 2/4 | 管理权限/日志 | 复用admin guard和同一用户库 |
| 3/4 | 管理布局 | 管理运行页面复用Task3布局 |
| 1–4/5 | 测试与部署 | 本地完成不等于生产完成，必须保留每层证据 |

各任务内部测试分别针对数据库竞态、权限、交互、指标和发布，未以修改文本断言替代行为测试。部署需要实际维护窗口和访问条件，不在研发中伪造完成。
