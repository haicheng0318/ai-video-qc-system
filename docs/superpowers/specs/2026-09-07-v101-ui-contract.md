# V1.01 界面实施约定

## 依据与边界

已批准的修订方案是功能与布局权威。本次实际打开需求系统入口，观察到深色底、紫色品牌强调、圆角卡片和明确模块入口。随后登录保护解除，实际看到“驾驶舱”：顶部月份筛选、刷新与更新时间，需求总量/完成量/完成率/人均4张指标卡，店铺渠道卡片显示目标/完成/缺口/进度，底部完成进度与平台分布图。初始窄面板中内容被横向截断，随后以1440×1000桌面断点检查了完整侧栏、四列指标与四列渠道卡片；不复刻窄屏截断问题。

另已只读查看“渠道监控”和“后台管理”：渠道页面在顶部周期选择下使用精确数字表、平台标签、进度条和平台汇总；后台用说明条、功能卡片、管理员列表与独立新增表单分区组织。参考后台的单元格编辑提示会自动保存，本次没有点击编辑单元格或填写表单，也未操作保存、导入、导出、账号创建或更改参考业务数据。其他弹窗与移动交互未逐页验证。检查后恢复驾驶舱和默认浏览器尺寸。

UI/UX 检索中 Data-Dense Dashboard 匹配内部运营场景，采用其高信息密度、响应式卡片、表格和明确状态指导。营销落地页模式不适用，不采纳。Next.js 检索给出不同大版本且未命中所需持久状态问题，不据此升级依赖。

## 视觉约定

- 深色侧栏/登录品牌区与浅色业务内容结合，紫色主操作，不把整站变成装饰性黑色大屏。
- tokens：背景 #F6F7FB、卡片 #FFFFFF、正文 #172033、次级 #596579、边框 #DCE1EA、强调 #6D28D9、强调浅底 #F0EAFE、侧栏 #151426、侧栏正文 #EAE7F4。语义成功 #167445、警示 #9A5700、失败 #B42318；白底正文要实测对比度，不单靠颜色区分状态。
- 系统中文字体栈，不下载外部字体；正文16px、表格14px、说明最低12px，数字 tabular-nums。间距8/12/16/24/32px，卡片圆角12px。
- 240px侧栏，桌面内容 min-width:0；小于900px折叠菜单，390px不产生页面横向滚动。表格可在有可见提示的局部容器横滚，不能撑破页面。
- 控件可触区域至少44px，明确focus-visible、aria标签、键盘关闭弹窗和焦点归还。动画仅轻量反馈并尊重reduced-motion。

基础 tokens 相对亮度计算（非整站视觉验收）：白底正文16.27:1、次级5.90:1、主色7.10:1、成功5.80:1、警示5.62:1、失败6.57:1；侧栏正文对侧栏底14.86:1。上述纯色组合满足普通文字4.5:1目标；透明度、浅色标签底、禁用态及实际组件仍需分别检查，不能由 tokens 推断全部页面合格。

## 导航与身份

前台：工作台 / 视频列表 / 上传评估 / 业务看板 / 优秀案例 / 反面案例 / 基准配置（按权限）/ 返回需求系统。
管理端：总览 / 账号 / 角色权限 / 视频与任务 / AI服务 / 存储 / 用量费用 / 业务配置 / 操作日志 / 安全 / 系统设置。
管理员入口独立 `/admin/login`，共享认证，普通用户不能通过前端地址绕过后端检查。角色决定导航，但导航不是权限边界。
访客仅工作台、自己的视频、上传评估、额度/到期提示、改密/退出。空数据不可用示例假数填充。

## 视频详情与同步

首屏双列：限高播放器 + 三个独立等级、状态、版本、更新时间与下一步。保留现有播放器和表单实例，不按整个video对象/更新时间改变React key。
8个标签页：内容评估、主管审核、运营投放数据、数据复盘、规则与最终建议、负责人确认、版本历史、操作记录。标签页切换隐藏而非卸载有未保存数据的表单；离开页面提醒，登录身份变化清理临时草稿。
三阶段按触发返回ID跟踪；查询暂停和业务失败区分；恢复查询不会重新提交。暂停/重试界面说明可恢复行为，不虚构进度百分比。
内容证据有可信时间戳才跳转；无证据显示未提供。版本对比明确两条记录，不能把不同版本AI结果混成当前建议。

## 数据与后台

指标标注来源、事件时间、北京时间筛选及去重口径。正式看板排除isTrial，不将无样本比率变成0%。当前积压单独注明快照。
账号创建/重置密码后一次性展示初始凭据并提示安全交付；离开即清除，不放URL/localStorage/日志。破坏性管理动作需要理由和明确确认。
服务、费用、备份和证书无只读数据源则展示未知/未接入与限制，不展示绿色正常。测试按钮只有真实实现的诊断，可能收费须说明并受控。

## 验收

真实浏览器检查登录、管理员、访客、列表筛选、详情自动更新不丢表单/播放位置、横竖视频、上传中断/重试及390px布局。模拟接口验收只证明UI逻辑，不替代真实生产模型和COS/OSS验证。
