## 2. 当前业务边界

- Qwen 只负责看视频并生成内容质量评估。
- GPT 仍负责运营/投放数据复盘与最终有效等级建议。
- 规则引擎仍由后端确定性代码实现，不放入 Prompt。
- 最终有效等级必须由内容负责人确认，AI 不能直接代替确认。
- 内容质量等级、数据表现等级、最终有效等级必须独立存储。

修改建议：

1. 延长产品展示时间，或在镜头中多次强调品牌标识。
2. 增加对强磁吸设计的实际操作演示，并配合口播说明优势。

## 4. 当前视频处理链路

```text
本地视频
→ 临时上传私有 OSS
→ 生成 V4 短时签名 URL
→ qwen3.5-omni-plus 识别
→ JSON Schema / Zod 校验
→ 评估结果与原始返回入库
→ 无论成功失败都删除 OSS 临时对象
→ 视频进入主管初审
```

## 5. 历史技术决策

- Gemini 项目因 `403 PERMISSION_DENIED / project denied access` 和地区/风控限制无法用于真实视频识别。
- 曾验证 Qwen Base64 直传：5 秒、2.4 MB 样片成功，评分 78，等级 B。
- 60 MB 业务视频的 Base64 请求超过百炼单字符串限制，因此改为 OSS 临时签名地址。
- OSS 只用于让远程模型临时读取，不改变系统本地永久存储策略。
