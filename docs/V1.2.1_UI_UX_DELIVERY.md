## 设计系统

`apps/web/app/experience.css` 是本次视觉层入口，加载于原全局样式之后，沿用原语义变量及兼容别名。

- 浅色为灰白工作台，深色为中性炭灰；克制的蓝紫品牌强调色。
- 背景、表面、悬停、文字、边框、状态、等级、图表、播放器、遮罩均有语义 Token。
- 复用 4/8/12/16/24/32/48 间距、4/6/8 圆角及系统中文字体。
- 150ms 反馈、180ms 入场；`prefers-reduced-motion` 下取消动画与过渡。
- 不新增组件框架、图标或动画运行依赖。当前基线没有 Lucide 包，保留现有轻量标记和原生控件，未为视觉优化升级依赖。

## 主题

`src/lib/theme.ts` 定义 Light/Dark/System 及首屏脚本；`ui/theme-switcher.tsx` 提供全局切换。

- 首屏在内容绘制前设置主题，避免等待 React 挂载。
- 本地 `aiqc-ui-theme` 偏好持久化；监听系统变化与跨标签页 storage 事件。
- 存储失败时降级为本标签页可用，不影响登录。
- 挂载时重新读取偏好，避免标签页初始化时错过变更。
- 无后端 API、用户字段或数据库持久化。
