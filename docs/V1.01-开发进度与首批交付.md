# V1.01 开发进度与首批交付

日期：2026-09-07。依据《修订开发方案与使用问题审查》启动分批开发。V1.01是本轮产品版本；此前全部需求继续保留在范围内，不因首批交付而取消。

## 1. 已完成内容

本地已实现首批用户体验修复：

- 内容评估按本次reviewId轮询，成功/失败自动同步结果和视频状态，无需刷新页面。
- 打开正在评估的视频时自动跟踪；重复点击前端互斥；后端原有权限与事务检查继续保留。
- 查询不重叠，单请求15秒超时，连续5次错误暂停，整轮自动查询20分钟上限；这些边界只暂停查询，不修改后台任务状态。
- 页面隐藏时降频，重新激活立即查询；离开时终止轮询请求并忽略迟到结果。
- 查询失败/暂停可手动重新查询，不创建新的付费评估。
- 播放器组件独立，宽高按原始比例限制在可用区域，最大高度min(60vh,560px)。
- 视频媒体错误时自动重新获取地址一次；仍失败提供手动重试，尝试恢复播放位置。不主动定时更换正在正常播放的链接。
- 登录接口401就地显示错误，不再触发公共过期会话重定向；受保护接口401行为保留。
- 页面产品标识改为V1.01。

## 3. 新增接口清单

`GET /api/videos/:id/content-reviews/:reviewId`

- 沿用JWT鉴权及视频资源可见性校验。
- reviewId必须属于指定videoId，非法或不匹配返回404；无权访问视频被拒绝。
- 返回videoStatus与评估公开字段，不返回rawResponse。
- 轮询不逐次新增“查看结果”日志，避免心跳撑大审计表；打开最新结果仍沿用原有查看审计，业务变更审计不变。
- 原latest接口保留。发布时API先于Web更新，避免新版前端访问未部署路由。
