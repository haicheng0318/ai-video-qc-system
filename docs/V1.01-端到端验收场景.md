# V1.01 端到端验收场景

本文件是待执行的验收要求，不是测试通过报告。执行结果以全量实施验收台账及各任务报告为准。测试使用隔离数据库、专用视频和注入式假供应商；真实云调用与生产切换另行授权。

## 核心业务链路

|场景|操作|必须观察到的结果|
|---|---|---|
|正式视频完整流程|编导提交→内容评估→主管批准→运营/投放数据→数据复盘→规则→最终建议→负责人确认|三个等级分别保存；最终建议完成不等于最终确认；确认人、时间、来源及操作日志完整|
|内容不合格|主管判定无效|后续数据及最终评估入口不可用，直接请求后端同样拒绝|
|返修|主管要求返修，编导提交新版本|新视频记录关联原视频；旧评估保留；对照页面显示真实版本与来源|
|样本不足|提供不足样本数据并完成复盘/规则|状态为 pending_data，不直接判 D 或无效；正式有效统计不包含该视频|
|来源改变|最终建议生成后新增主管意见或运营数据，再尝试确认旧建议|服务端拒绝陈旧建议，要求基于当前来源重新评定；历史建议仍可追踪|
|权限边界|编导、主管、运营、投放、负责人依次尝试无权操作|无权 API 拒绝，且数据库未发生副作用；前端隐藏按钮不作为唯一证据|

## 会话与访客

|场景|操作|必须观察到的结果|
|---|---|---|
|首次登录|管理员创建访客，访客首次登录后直接请求视频接口|必须先改密；改密前只能访问明确允许的身份/改密/退出接口|
|管理入口|非管理员登录 /admin/login|不产生有效管理会话；不能仅靠跳转前台掩盖权限缺陷|
|立即撤销|两浏览器会话登录，管理员停用、归档、重置密码或撤销会话|相应会话后续 API 请求失败；前端明确提示重新登录，不无限刷新|
|CSRF|外站 Origin、缺少 CSRF 头、旧 Bearer Token 调用写接口|拒绝且无副作用；合法同源 Cookie 请求可成功|
|访客隔离|访客甲尝试访客乙的视频、播放、任务、报告及管理接口|逐对象拒绝；仅自身内容评估可用；无数据复盘或最终确认权限|
|试用隔离|访客完成评估后改为正式角色|历史视频仍标记试用；正式看板分子、分母、趋势和排行都排除试用|
|额度并发|剩余一个名额时同时请求两次；重复提交同一个业务键|不同业务最多一个成功；同业务幂等；账本与余额一致|
|调用不确定|供应商调用前失败、调用后中断分别恢复|调用前按约定释放；调用后不确定不虚假退款，不自动重复付费调用|
|最后管理员|两个管理员并发互相停用或降权|至少保留一个有效管理员，不出现全员锁死|

账号停用后的应用 API 权限必须立即失效；已经签发的对象存储 URL 可能在有效期内仍可用，必须明确记录实际 TTL，不能声称已即时撤销云端签名。

## 用户界面与弱网

|场景|操作|必须观察到的结果|
|---|---|---|
|无需刷新|分别触发内容、数据、最终建议三个阶段|页面自动出现对应 ID 的结果；网络中只出现一次主动触发，不靠刷新或重复 POST|
|状态保留|输入未保存表单、播放视频至中间，等待轮询完成并切换标签|表单内容、播放器元素及播放进度不因轮询被重建|
|旧请求|视频甲查询未结束时进入视频乙|甲的延迟响应不能写入乙页面；卸载后不再更新组件|
|短暂网络失败|轮询中断网并恢复|保留已有结果，展示暂停/恢复提示；无并发查询洪泛，无自动收费重试|
|上传取消|上传中取消，然后重新选择视频|进度来源于实际字节；取消后资源与额度按约定释放，不误删已确认对象|
|上传确认重试|上传成功但确认响应丢失，使用同一业务键再确认|只创建一条视频记录并扣一次额度；原输入仍可恢复|
|适配|桌面 1440px 与移动端 390px 实际浏览器访问|播放器限高且完整呈现；表格受控滚动；页面无整体横向溢出；控件可点击且焦点可见|
|证据定位|有时间戳与无时间戳的两种评估记录|只对真实可验证时间戳提供跳转；缺少时间戳清晰说明，不猜测时间|

## 管理数据可信度与发布

|场景|操作|必须观察到的结果|
|---|---|---|
|统计边界|构造北京时间月初前后一秒、试用、未确认、无样本记录|日期与口径准确；无分母比例显示无数据；与当前积压统计明确区分|
|任务恢复|worker 在调用前、调用后分别退出，旧 worker 延迟回写|租约与 fencing 生效；旧结果不能覆盖新结果；不确定任务进入人工处理|
|受控重试|对 needs_attention 重试两次并发请求|明确费用提示、原因与审计；不能创建两个活动任务或绕过业务状态|
|未知指标|没有云账单、备份或证书采集数据|显示未接入/未知与数据来源，不能显示 0 元、正常或已备份|
|导出安全|输入包含 HTML、CSV 公式及长文本，导出报告和日志|内容被安全编码；无原始响应、签名 URL、密钥或堆栈；有权限校验和审计|
|数据库演练|空库迁移、旧版含数据迁移、备份恢复到独立数据库|核心表/等级/外键/日志保持；恢复样本核对通过，不覆盖已有数据库|
|发布门槛|全套测试、构建、镜像启动、依赖风险审查|每层有命令及退出码；未授权真实调用/生产操作保持待执行，不伪造上线完成|
