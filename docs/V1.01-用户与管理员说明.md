# V1.01 用户与管理员说明

本说明描述当前本地实现。正式地址、账号开通时间与上线通知以负责人发布为准；本轮未在生产创建账号。

## 登录与账户

普通用户进入 `/login`，管理员可进入 `/admin/login`。二者使用同一个账号体系，管理入口仅允许管理员登录。初始密码由管理员单独交付，首次登录被要求改密时，完成改密后才能使用视频功能。不要把密码、Cookie 或一次性重置密码复制进视频说明、截图、工单或日志。

登录状态由浏览器的 HttpOnly Cookie 与服务器会话共同管理。退出、重置密码、停用、归档或撤销会话后，相应会话的后续请求会被拒绝；无需清理 localStorage 来“重新获得权限”。旧 Bearer Token 在 V1.01 不再使用。

访客可以查看到期时间及授权额度，使用自己的视频上传、内容评估和受控报告；没有主管审核、运营数据、最终确认或管理权限。到期后需由管理员续期。访客期间创建的视频及其返修版本一直保留试用标记，即使后来转为正式角色，也不自动计入正式看板。

## 从提交到正式结论

1. 编导在“提交视频”选择 MP4、MOV 或 WebM，填写用途、品牌、平台等信息。选择视频后会检查基本格式；上传时显示实际字节进度。视频编码是否可播放还取决于浏览器支持。
2. 上传完成后，在详情页触发内容评估。成功创建的任务在后台执行，离开页面不会取消。界面只读查询对应评估编号，不需要反复点击触发。
3. 主管查看团队视频、内容等级和问题，决定通过发布、要求返修或内容无效。返修需要创建新版本，保留原版本和原评估；内容无效不会进入运营数据流程。
4. 运营或投放按视频用途录入真实结果。每次保存生成新快照，历史数据不覆盖。百分数直接填写百分数数值，例如 2.35 表示 2.35%；ROI 按倍数填写。页面提示来源过期时先读取最新快照再提交。
5. 对最新数据快照触发数据复盘，再由负责人或管理员执行规则判断和最终建议。内容、数据与最终有效等级分别展示，不能把其中一个当成全部结论。
6. 负责人核对当前来源和规则边界后确认正式结论。偏离 AI 建议需要说明原因；内容与数据冲突需要人工确认说明。数据不足保持“待补充数据”，不判 D 或无效。
7. 已正式确认的有效视频可标记优秀案例；正式无效视频可标记反面案例。低有效视频不进入两类案例库。案例操作保留原因和审计，不改写正式结论。

最终确认不是普通草稿保存：已确认记录不能在当前页面重复修改。主管源记录或数据来源发生变化时，旧建议不能继续确认，应由负责人核查当前来源后重新走受控评定流程。

## 页面与常见情况

详情页把播放器、三级等级和当前下一步放在前部，下方八个标签保留各环节内容。切标签不会重建播放器或已输入的表单；离开未保存页面时会提示。列表筛选与页码记录在地址栏，可返回继续查看。

| 提示/情况 | 处理方法 |
|---|---|
| 正在排队/处理中 | 等待后台 worker；可离开再回来，不重复付费触发 |
| 状态查询失败/暂停 | 检查网络后“重新查询状态”；查询失败不等于模型任务失败 |
| 模型评估失败 | 查看公开错误；管理员根据失败阶段决定是否重试，原始记录保留 |
| 需人工处理/外部结果不确定 | 可能已发起供应商调用；不能把它当作未收费，先核对再决定受控重试 |
| 播放链接失效 | 播放器自动续签一次，再失败可“重新加载视频”；这不重新评估视频 |
| 上传中断 | 重新选择文件后按页面提示重试；同一次直传的确认重试沿用原票据，不重复扣额度 |
| 额度不足/账号到期 | 联系管理员；刷新页面不能扩大额度或延长有效期 |
| 来源过期或确认冲突 | 已有新快照、源意见变化或他人先完成；读取最新状态后核对，不盲目重复提交 |

同一个已签发的对象存储播放 URL 可能在有效期内继续有效，即使账号已被停用。停用会阻止新的应用 API 和续签请求；已有 URL 要到 TTL 到期才失效。不要把播放链接当作可公开分享的永久地址。

## 角色分工

| 角色 | 主要权限 |
|---|---|
| 管理员 | 管理账号、额度、会话、配置和系统运行，执行全部授权业务环节 |
| 内容负责人 | 查看业务视频、规则与最终评定，确认正式等级和案例；无系统管理权限 |
| 编导主管 | 查看本人及直属团队视频，执行主管初审 |
| 编导 | 上传及查看自己的视频、触发自己的内容评估、提交返修 |
| 运营 | 查看业务视频，补充适用的非投放数据并触发数据复盘 |
| 投放 | 查看业务视频，补充投放类数据并触发数据复盘 |
| 访客 | 限定期限与额度内使用自己视频的试用功能 |

运营/投放的责任按视频类型及是否投放共同判断；商品卡或“其他”勾选投放时由投放角色管理结果数据。前端按钮仅用于引导，最终权限由后端校验。

## 管理员运行说明

管理员通过 `/admin` 的运行中心和账号管理工作，不需要另建“后台账号”。单个或批量创建账号、续期、启停、归档、重置密码、撤销会话和调整额度均填写原因。一次性密码只在创建/重置结果中展示，及时通过已批准渠道交付，不会在列表中再次展示。最后一个有效管理员受到并发保护，不能把所有管理员同时停用或降权。

上传次数和评估次数可按日、月或长期额度管理；存储字节额度为长期占用量，不随日/月归零。任务入队先预占业务额度；真正到达外部调用边界再记用量。供应商请求次数、业务额度、估算费用和实际账单是不同指标；未接入账单时显示未知，不能按估算报销。

任务中心显示等待/运行/终态、尝试历史和有限错误分类。受控重试需要确认费用可能发生并填写原因，生成新记录且关联旧任务。相同失败任务并发重试只能成功一次；已经被替代的任务不能再反复触发。

存储页展示的是系统已登记容量、上传票据和新采集的临时对象记录，不等于云端全量清单。临时清理失败需要核对云端前缀及生命周期；不要直接删除未知对象。配置只影响之后的新任务，已排队任务保留原输入快照和配置来源。

日志、用量和报告导出都需要原有权限，管理导出还需要原因并记录审计。导出上限为 1000 条，未知值留空；报表中不包含模型原始返回、密钥、对象内部路径或签名凭据。不要利用导出推算缺失的云账单或历史数据。

依赖页分别展示 API 存活、数据库就绪及 worker 心跳。AI 连通、真实云存储、服务器资源、备份、证书、云账单未采集时会显示未探测/未接入。API“健康”不表示这些外部依赖都正常。

部署、密钥、备份、恢复和真实付费诊断由有权限的维护人员按 [发布手册](V1.01-本地验收与发布手册.md) 执行，不通过普通账号页面绕过维护门禁。
