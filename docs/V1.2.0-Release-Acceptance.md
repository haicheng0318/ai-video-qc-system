# V1.2.0 Release Acceptance

Release Acceptance is an opt-in, required end-to-end test against a fresh isolated PostgreSQL database. It exercises the real Nest application, HTTP routes, persistence, and worker while replacing all model clients with deterministic synthetic fixtures. It must never point at a shared, staging, or production database.

## Isolated database contract

The test accepts only a loopback PostgreSQL URL on an allowlisted local test port and database name. For a fresh database, apply the checked-in migrations with `npx prisma migrate deploy` before running the test. Do not seed the database. The test itself requires the database to contain zero users and fails rather than skips if the required environment is incomplete.

Example environment for a disposable PostgreSQL container bound only to localhost:

```sh
export QC_LOCAL_ACCEPTANCE=1
export RELEASE_TEST_DATABASE_URL='postgresql://release_test:<local-test-password>@127.0.0.1:55443/release_test?schema=public'
export RELEASE_TEST_MEDIA_PATH='/tmp/aiqc-v120-release-synthetic.webm'
npm run test:release-acceptance
```

The release test verifies formal V1.1 content decisions, revision uploads from automatic C/D gates, blocking of metric/data-rating/result-review operations by active Hold, active Appeal, and suspected/confirmed compliance, and admin read-only access to hidden/trashed video records. The model provider calls are mocked in-process; `paidModelCalls` must remain zero.

## Browser acceptance

Run the local web server on loopback and execute `npm --workspace @ai-video-qc/web run test:browser:v120` with `QC_LOCAL_REHEARSAL=1` and the bundled Playwright module path configured when needed. The browser suite uses mocked local API routes and synthetic media only. It checks optional cover upload and that a no-cover card preview seeks to the first second.

## Non-skippable invocation

`npm run test:release-acceptance` sets `RELEASE_ACCEPTANCE_REQUIRED=1`. Missing database or media configuration is an error, not a skipped test. The generic API unit suite may skip this opt-in test; the dedicated release command must report it as executed and passing.
