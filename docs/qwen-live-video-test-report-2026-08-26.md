## 8. 风险与建议

1. Base64 编码会使请求体积约增加三分之一，并在编码期间占用后端内存；当前默认通过 `QWEN_MAX_LOCAL_VIDEO_MB=100` 限制本地视频大小。
2. 本次真实请求可能消耗百炼免费额度或产生模型费用。
3. API Key 曾直接出现在聊天内容中，建议完成测试后在百炼控制台轮换 Key，并只将新 Key 保存到本地 `.env`。
4. 后续正式验收建议通过业务接口跑一条完整视频，使模型原始结果、内容等级、操作日志和状态流转形成可审计记录。
